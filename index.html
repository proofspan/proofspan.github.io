Intelligence needs proof.

Proofspan is mathematical verification infrastructure for AI. It recomputes the numbers in machine-generated financial research, dates every figure against the moment the analysis claims to know it, and stress-tests the statistics behind every forecast.

Try the verification engine ↓Open the application

what you are looking atEach point is a numerical claim. The plane is the check. Confirmed claims continue; refuted ones are deflected and marked. Every verdict carries the equation it used.

Demonstration

An AI said revenue grew 25%. The filings say otherwise.

POST /api/v1/validate · validator revenue_growth · tolerance inferred from the claim's stated precision

Enter two reported figures and the growth a model asserted. Proofspan recomputes the number independently and returns a verdict with the equation, the discrepancy and the tolerance it used.

01 — Mathematical verification

Growth, margins, ratios, CAGR and cross-period sums recomputed from source values with explicit units, periods and tolerances. Three-valued verdicts: a check that lacks data says so.

02 — Point-in-time consistency

A period ending before the cutoff proves nothing. Publication and availability timestamps, restatements and timezone-aware comparisons catch look-ahead leakage with the lead time.

03 — Statistical robustness

Error metrics, interval coverage, calibration, bootstrap and walk-forward validation with a leakage guard. Every report names its sample size, assumptions and warnings.

Python engines · HTTP API · Python SDK · 43-case labelled benchmark, 30/30 planted problems detected, 0/13 false positives. Runs locally; no cloud, no key required.
